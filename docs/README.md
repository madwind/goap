| 文档 | 内容 |
| --- | --- |
| [使用指南](USAGE.md) | 安装、场景绑定、Action、Goal 与世界状态 |
| [设计与执行](DESIGN.md) | 核心模块、搜索、执行与重规划 |
| [成本模型](COSTS.md) | 动态成本与独立规划器 |
| [调度与性能](SCHEDULING.md) | 预算、后台任务与性能指标 |
| [编辑器与调试](DEBUGGING.md) | 定义浏览、预览、运行时观察 |
| [验证](TESTING.md) | 保留的回归测试与导出检查 |

示例操作见 [goap_example/README.md](../goap_example/README.md)。
